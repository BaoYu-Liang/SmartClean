# SmartClean
Prototipo de monitoreo del nivel de llenado de contenedores de residuos mediante un sensor ultrasónico, reglas lógicas y una interfaz básica en Java, para identificar oportunamente la necesidad de recolección y contribuir a mejorar la gestión de residuos sólidos.
